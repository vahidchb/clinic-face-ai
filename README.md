# clinic-face-ai

تشخیص چهره برای کلینیک زیبایی — قدم اول شبیه‌ساز زیبایی.
Face diagnosis for an aesthetic clinic — step 1 of the aesthetic simulator.

بیمار سلفی می‌فرستد، سیستم کیفیت پوست را تحلیل می‌کند و بوتاکس / فیلر لب و گونه
را به‌صورت ناحیه + شدت بصری پیشنهاد می‌دهد. تصمیم و مقدار دقیق فقط با پزشک است.

## وضعیت فعلی — ۲۰۲۶-۱۱-۲۶

- رابط کاربری: سبک GlowAI صورتی (صورتی / یاسی ملایم)، فارسی راست‌چین، فونت وزیرمتن.
- تحلیل فعلی **نمایشی** است: `POST /api/analyze` یک JSON نمونه برمی‌گرداند
  (Glow Score ‏۷۶ و ۵ شاخص پوست). تحلیل واقعی بعد از اتصال درگاه هوش مصنوعی
  (گیسو یا سپند) جایگزین می‌شود.
- روی هر پیش‌نمایش نوشته شده: «پیش‌نمایش است، نه تضمین نتیجه؛ مقدار دقیق
  (واحد / حجم) را فقط پزشک تعیین می‌کند.»
- پیش‌نمایش «بعد»: بعد از انتخاب درمان‌ها، همان عکس با فیلتر نمایشی
  (قدرت فیلتر با شدت خفیف / متعادل / محسوس تغییر می‌کند)، اسلایدر مقایسه‌ی
  قبل / بعد و زوم ۱ تا ۳ برابر با جابه‌جایی با درگ. این فقط برای تست بصری
  است؛ عکس واقعی «بعد» بعد از اتصال مدل تصویری می‌آید و چهره عوض نمی‌شود.

## تکنولوژی

- بک‌اند: Python + FastAPI — عکس را می‌گیرد، به مدل می‌فرستد، JSON برمی‌گرداند.
- فرانت‌اند: HTML + CSS + jQuery (جی‌کوئری کتابخانه‌ی جاوااسکریپت است و در
  مرورگر کار می‌کند؛ کنار بک‌اند پایتون قرار می‌گیرد).

## اجرا — کپی کن، تایپ نکن

```bash
python -m pip install -r requirements.txt
python -m uvicorn app:app --reload --port 8000
```

بعد مرورگر را باز کن:

```text
http://127.0.0.1:8000
```

## ساختار

```text
app.py               FastAPI — سرو صفحه + API نمایشی تحلیل
requirements.txt
```

## قدم بعدی — مسیر واقعی (نه فیلتر نمایشی)

فیلتر روی عکس نمی‌تواند شکل لب، عمق چروک یا تقارن را نشان دهد. مسیر واقعی:

1. فرستادن ۱-۲ سلفی تست و تحلیل دقیق در چت، برای جایگزینی داده‌ی نمایشی.
2. ساخت حساب گیسو (اول) یا سپند (پشتیبان) و گرفتن کلید API.
   گیسو: `https://ir.gisoo.pro/api/v1` — سپند: `https://api.sepandsoftware.ir/v1`
   کلید را هیچ‌وقت در کد یا چت نگذارید؛ فقط متغیر محیطی:
   `AI_GATEWAY_BASE_URL` ، `AI_GATEWAY_API_KEY` ، `AI_VISION_MODEL` ، `AI_IMAGE_MODEL`
3. تست حفظ چهره — `scripts/face_preservation_test.py`:
   ۳ سلفی در `test_photos/`، فقط بوتاکس پیشانی، ۳ شدت، ۹ خروجی.
   اگر در ۲ تا از ۳ عکس چهره جابه‌جا شد، مدل را عوض کنید، محصول را نسازید.
   مدل پیش‌بینی‌شده: Nano Banana 2 Lite (`gemini-3.1-flash-lite-image`،
   ‎۰٫۰۳۳۶ دلار به‌ازای عکس 1K)؛ جایگزین قوی‌تر برای حفظ چهره:
   Nano Banana 2 (`gemini-3.1-flash-image`، ‎۰٫۰۶۷ دلار).
4. وقتی تست پاس شد، `POST /api/simulate` را به مدل تصویری وصل کنید —
   تا آن موقع عمداً خطای `not_ready` می‌دهد تا عکس جعلی ساخته نشود.

با درگاه وصل‌شده:

```bash
set AI_GATEWAY_BASE_URL=https://ir.gisoo.pro/api/v1
set AI_GATEWAY_API_KEY=...
python -m uvicorn app:app --reload --port 8000
```
