# clinic-face-ai

تشخیص چهره برای کلینیک زیبایی — قدم اول شبیه‌ساز زیبایی.
Face diagnosis for an aesthetic clinic — step 1 of the aesthetic simulator.

بیمار سلفی می‌فرستد، سیستم کیفیت پوست را تحلیل می‌کند و بوتاکس / فیلر لب و گونه
را به‌صورت ناحیه + شدت بصری پیشنهاد می‌دهد. تصمیم و مقدار دقیق فقط با پزشک است.

## وضعیت فعلی — ۲۰۲۶-۱۱-۲۶

- رابط کاربری: سبک GlowAI صورتی (صورتی / یاسی ملایم)، فارسی راست‌چین، فونت وزیرمتن.
- درگاه وصل‌شده: **هرموز** (`https://api.hormouz.net/v1`) — تحلیل واقعی و عکس
  واقعی «بعد» هر دو از هرموز می‌آیند. بدون کلید درگاه، تحلیل نمایشی برمی‌گردد
  و `POST /api/simulate` خطای `not_ready` می‌دهد تا عکس جعلی ساخته نشود.
- تست حفظ چهره **پاس شد (۳ از ۳)**: ۲ عکس روی گیسو + ۱ عکس روی هرموز —
  چهره، چشم، بینی، لب، ریش، مو و پس‌زمینه عوض نشد؛ فقط ناحیه‌ی درمان تغییر کرد.
- روی هر پیش‌نمایش نوشته شده: «پیش‌نمایش تصویری است، نه تضمین نتیجه؛
  تصمیم نهایی با پزشک است.»
- پیش‌نمایش «بعد»: دکمه‌ی «ساخت عکس واقعی بعد» عکس واقعی را با مدل تصویری
  می‌سازد و جای فیلتر نمایشی می‌گذارد؛ اسلایدر مقایسه‌ی قبل / بعد و زوم
  ۱ تا ۳ برابر با جابه‌جایی با درگ هم هست.

## تکنولوژی

- بک‌اند: Python + FastAPI — عکس را می‌گیرد، به مدل می‌فرستد، JSON برمی‌گرداند.
- فرانت‌اند: HTML + CSS + jQuery (جی‌کوئری کتابخانه‌ی جاوااسکریپت است و در
  مرورگر کار می‌کند؛ کنار بک‌اند پایتون قرار می‌گیرد).

## اجرا — کپی کن، تایپ نکن

```bash
python -m pip install -r requirements.txt
python -m uvicorn app:app --reload --port 8000
```

بعد مرورگر را باز کن:

```text
http://127.0.0.1:8000
```

## ساختار

```text
app.py               FastAPI — سرو صفحه + API نمایشی تحلیل
requirements.txt
static/
  index.html         صفحه‌ی اصلی، فارسی راست‌چین
  style.css          پالت GlowAI صورتی / یاسی
  app.js             منطق jQuery — آپلود، اسکن، ناحیه‌ها، کارت‌های درمان
```

## اتصال درگاه — هرموز (۲۰۲۶-۱۱-۲۶)

1. در [app.hormouz.net](https://app.hormouz.net/en/) ثبت‌نام کنید (موبایل + پیامک)
   و از داشبورد یک کلید API بسازید. ثبت‌نام ۰٫۲۵ دلار اعتبار هدیه می‌دهد
   (حدود ۷ عکس)؛ بدون شارژ هم می‌شود تست کرد.
2. کلید را هیچ‌وقت در کد یا چت نگذارید؛ فقط در `.env` (نمونه در `.env.example`):

```bash
AI_GATEWAY_BASE_URL=https://api.hormouz.net/v1
AI_GATEWAY_API_KEY=...
AI_VISION_MODEL=google/gemini-3.1-flash-lite
AI_IMAGE_MODEL=google/gemini-3.1-flash-lite-image
```

3. تست حفظ چهره — `scripts/face_preservation_test.py`:
   ۳ سلفی در `test_photos/`، فقط بوتاکس پیشانی، ۳ شدت، ۹ خروجی.
   اگر در ۲ تا از ۳ عکس چهره جابه‌جا شد، مدل را عوض کنید، محصول را نسازید.
   نکته‌ی هرموز: مدل تصویری فقط از مسیر چت کار می‌کند
   (`POST /chat/completions`، عکس خروجی در `message.images`)؛ مسیر
   `/v1/predictions` عکس ورودی data URL را قبول نمی‌کند و به‌جای ویرایش،
   یک عکس تازه می‌سازد — از آن استفاده نکنید.

## هزینه — قیمت هرموز (۲۰۲۶-۱۱-۲۶، اندازه‌گیری‌شده)

- تحلیل پوست: `google/gemini-3.1-flash-lite` — هر تحلیل حدود ‎۰٫۰۰۱ دلار.
- عکس «بعد»: Nano Banana 2 Lite — هر عکس ‎۰٫۰۳۴ دلار (روی گیسو ‎۰٫۰۶ دلار بود).
- پرهیز: Pro، 2K/4K، و تست هم‌زمان ۵ درمان.
- شارژ هرموز: حداقل ۱ دلار، فقط عدد صحیح؛ روی مبلغ ۱۰٪ کارمزد خدمات +
  ۱۰٪ مالیات + کارمزد درگاه (حداکثر ۲۲٬۰۰۰ تومان). برای شارژهای کوچک
  کارمزد درگاه سهم بزرگی دارد — یک‌جا مبلغ بیشتر شارژ کنید.

## اجرا با درگاه — کپی کن، تایپ نکن

ویندوز — اول `.env` را بسازید: `.env.example` را کپی کنید به `.env` و کلید
خودتان را از داشبورد هرموز جلوی `AI_GATEWAY_API_KEY=` بگذارید. بعد:

```bash
python -m pip install -r requirements.txt
.\run.bat
```

`run.bat` خودش `.env` را می‌خواند و سرویس را روی پورت ۸۰۰۰ بالا می‌آورد.
اگر ترمینال VS Code شما PowerShell است، `.\run.bat` همان‌جا هم کار می‌کند.
روش دستی (بدون run.bat) — در همان پنجره‌ی cmd اول `.env` را لود کنید:

```bash
for /f "eol=# tokens=1,* delims==" %a in (.env) do set %a=%b
python -m uvicorn app:app --reload --port 8000
```

بعد مرورگر را باز کن: `http://127.0.0.1:8000` — عکس را آپلود کن،
«شروع تحلیل» را بزن، درمان‌ها را انتخاب کن، بعد «ساخت عکس واقعی بعد».
